## Usage: Combine Area and CD3 Quantification Files

This script combines QuPath-exported `areas` and `cd3` text files into organized per-islet and per-slide summary CSV files.

### 1. Prepare input files

Place paired `*_areas.txt` and `*_cd3.txt` files in the same folder.

Example:

```text
T1D_test/
├── 12345_areas.txt
├── 12345_cd3.txt
├── 67890_areas.txt
└── 67890_cd3.txt
```

The file ID before `_areas.txt` and `_cd3.txt` must match.

For example:

```text
12345_areas.txt
12345_cd3.txt
```

### 2. Run the script

Example command:

```bash
python combine_dataset_clean.py \
  --text_folder ./T1D_test \
  --organized_csv_folder organized \
  --organized_folder ./T1D_test/organized \
  --final_folder ./T1D_test/final
```

### Arguments

| Argument | Description | User should modify? |
|---|---|---|
| `--text_folder` | Folder containing paired `*_areas.txt` and `*_cd3.txt` files | **Yes** |
| `--organized_csv_folder` | Name of the subfolder where organized per-islet CSV files will be saved | Usually no |
| `--organized_folder` | Full path to the organized output folder | **Yes, if `--text_folder` is changed** |
| `--final_folder` | Full path to the final output folder | **Yes, if `--text_folder` is changed** |


### 3. Output structure

After running the script, the following files and folders will be generated automatically:

```text
T1D_test/
├── 12345_areas.txt
├── 12345_cd3.txt
├── 67890_areas.txt
├── 67890_cd3.txt
│
├── 12345_areas.csv
├── 12345_cd3.csv
├── 67890_areas.csv
├── 67890_cd3.csv
│
├── organized/
│   ├── 12345.csv
│   └── 67890.csv
│
└── final/
    ├── organized_12345.csv
    ├── organized_67890.csv
    │
    └── per_slide_data/
        └── per_slide_info.csv
```

### 4. Output files

| Output file | Description |
|---|---|
| `*_areas.csv`, `*_cd3.csv` | CSV files converted from the original tab-delimited `.txt` files |
| `organized/{image_id}.csv` | Per-islet file containing CD3 count, Glucagon area, Insulin area, Background area, and size information |
| `final/organized_{image_id}.csv` | Filtered per-islet file after removing rows where both Glucagon and Insulin are zero |
| `final/per_slide_data/per_slide_info.csv` | Per-slide summary file containing INS+/− and CD3+/− islet counts |

### 5. Notes

- The script automatically creates the `organized`, `final`, and `per_slide_data` folders if they do not already exist.
- Multiple paired input files are processed together.
- The final `per_slide_info.csv` stacks all processed slides into one summary file.
- If an `_areas.txt` file does not have a matching `_cd3.txt` file, that sample will be skipped.
- CD3-positive islets are defined as islets with `Num Positive > 6`.
